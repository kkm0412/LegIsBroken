## 게임 소개
한밭대학교 인간과 컴퓨터 상호작용 25년/2학기 수업에서 제작한 텀프로젝트 결과물입니다.

주인공은 교통사고로 절벽에서 추락했습니다
낙법 덕분에 살아남았지만 다리를 잃었습니다
구조연락을 할 방법은 없습니다, 직접 절벽 위로 다시 올라가는 방법 외에는요.

손으로 바위를 잡고 올라가 절벽을 등반하세요!
다리는 없지만 L.E.G.S.(Lifting Enhancement Grabbing System)은 있습니다!
LEGS로 잡을 수 없는 절벽에 고정시킬수 있습니다.

과연 절벽 위까지 다시 올라가 구조를 받을수 있을까요?

## 게임 플레이 방법
(메타퀘스트3 컨트롤러 기준입니다)

시작 방법:
시작화면에서 차량 중앙에 있는 빨간 버튼을 중지 트리거로 누르면 게임이 시작됩니다.

기본적인 이동방법:
중지 트리거를 뉼러 바위를 잡거나 바닥을 잡을수 있습니다.
잡은 상태로 손을 움직여 몸을 이동할수 있습니다.
잡고 손을 빠르게 움직이면 몸이 더 빠르게 이동합니다.
몸이 빠르게 움직일때 트리거를 놓으면 몸이 빠르게 튀어나갑니다.
일반적으로 갈수 없는 거리를 튀어올라 이동할수 있습니다.

LEGS는 몸의 중앙 제일 아래에 있습니다.
중지 트리거로 LEGS를 잡습니다.
LEGS를 잡은 상태로 검지 트리거를 눌러 작동시킵니다.
아무 벽에나 붙여 작동시키면 그 벽에 고정됩니다.
중지 트리거를 놓으면 원래 몸의 중앙 아래로 이동합니다.
손으로는 도저히 못잡는 구간이 생길 때 LEGS를 이용하여 거리의 한계를 극복하세요.

주의사항:
고정된 위치에서 플레이하세요. LEGS 부착위치가 몸이 있는 위치입니다.
따로 몸을 원위치로 북귀 시키는 로직은 못 만들었습니다.
